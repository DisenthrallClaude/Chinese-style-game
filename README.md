# 山海机关录 · Shanhai Mechanica

> 「引水为力，铸械为兵，守此一谷山川。」

一款以《山海经》与**机关术**为骨的 3D 塔防策略游戏，运行在浏览器里，
**零外部素材** —— 山川、楼阁、水车、齿轮、异兽、纹理、音效，全部在运行时程序化生成。

在线试玩：**https://disenthrallclaude.github.io/Chinese-style-game/**

视觉基调的拆解见 [docs/style.md](docs/style.md)。

## 玩法

昆仑之墟东南三百里，有谷曰**栖梧**。谷民世代以机关术营生，引溪为力，驱轮为兵。
《山海经》所载凶兽破封而出，自左右两处山口奔涌而下，直取谷心的**社树**。

### 三条核心规则

| 规则 | 说明 |
| --- | --- |
| **引水生力** | 机关不会凭空运转。**水车**（临溪）与**风车**吐纳*机力*，经**传动枢**结成网络送到各处。没接上网的机关直接停机；机力供不应求则全谷射速按比例下降。 |
| **五行相克** | 金克木、木克土、土克水、水克火、火克金。打对属性伤害 **×1.85**，打错只有 **×0.62**。每一波的凶兽属性都在右上角预告里写着。 |
| **昼夜轮转** | 部分波次在夜里来袭：凶兽气血更厚、脚力更快；但谷中灯火通明，机关**射速 +12%**。烛龙更会强行倒转昼夜。 |

### 九种机关

连弩机（木·速射）· 霹雳车（土·溅射）· 流火筒（火·锥形灼烧）· 寒泉阵（水·减速领域）
金锋轮（金·环身斩击）· 引雷桩（金·连锁闪电）· 水车（发力）· 风车（发力）· 传动枢（传动）

每种三阶，升阶会实实在在地改变外形 —— 单弩变三连弩、四扇风车变八扇、雷桩长出更多铜环。

### 十三种凶兽

讙 · 猰貐 · 蠃鱼 · 鵸鵌 · 毕方 · 化蛇 · 相柳 · 九尾狐 · 饕餮 · 帝江 · 穷奇 · 夔 · 烛龙

各有脾性：**相柳**斩之分身、**饕餮**啃噬机关使其卡死、**九尾狐**为同类加持、
**帝江**免疫减速、**化蛇**发大水淹停水车、**夔**一声雷震瘫周围机关、
**烛龙**边走边回血还会颠倒昼夜。飞行的凶兽（鵸鵌、毕方、穷奇）**不循兽道**，直扑社树。

### 三道秘术

**天雷**（Q）落雷轰击并震慑 · **玄冰**（F）冻结一片 · **归元**（G）十息内全谷机关射速 +70% 且无视断网

## 操作

| 操作 | 作用 |
| --- | --- |
| `左键拖拽` | 抓住地面平移（松手有惯性滑行） |
| `右键拖拽` / `中键` / `Shift+左键` | 转视角 |
| `滚轮` | 对准光标推拉；拉近时自动压低俯角 |
| `光标贴近屏幕边缘` | 自动推屏 |
| `WASD` / `方向键` | 平移；`[` `]` 旋转 |
| `1` – `9` | 选择机关 |
| `左键单击` | 放置 / 选中机关 / 施放秘术 |
| `空格` | 催兵；交战中按则切换 ×1 / ×2 / ×3 倍速 |
| `C` / `X` | 升阶 / 拆解选中的机关 |
| `L` | 显示机力网络 |
| `N` | 切换昼夜 |
| `R` | 复位视角 |
| `M` | 静音 |
| `Esc` | 取消当前选择 |

## 运行

不需要构建步骤，只要一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或任意等价物（`npx serve`、nginx、GitHub Pages…）。
`three.js` 已随仓库附带在 `vendor/three/`，通过 import map 解析，因此**离线可玩**。

要求：支持 WebGL2 的现代浏览器。引擎自带帧率自适应，掉帧时会自动降低内部渲染分辨率。

## 技术

* **three.js r185**（vendored），ES module + import map，无打包器。
* **全部资源程序化生成**：
  * `src/core/textures.js` —— 木纹、筒瓦、青石、绢帛、铜锈、窗棂、树叶⋯ 用 Canvas2D 逐像素绘制，再由亮度反解法线图与粗糙度图。
  * `src/world/geo.js` / `architecture.js` —— 台基、柱、额枋、斗拱、**反宇飞檐**的中式屋顶曲面（按到檐口的内推距离求坡度，四角起翘）。
  * `src/world/terrain.js` —— 山谷高程场：梯田、环谷山体、喀斯特峰林，向北开一道谷口露出层叠远山。
  * `src/game/beasts.js` —— 异兽由躯干／四肢／翼／尾／首等部件拼出，肢体动画写在顶点着色器里，整族凶兽一次 draw call。
* **渲染**：ACES 调色 + 分离色调、UnrealBloom、基于深度的**丁达尔光柱**、天空烘焙成 PMREM 环境光、指数雾 + 掠射雾带。
* **音效**：`src/core/audio.js` 用 WebAudio 振荡器与噪声实时合成，无音频文件。
