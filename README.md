# 山海机关录 · Shanhai Mechanica

> 「引水为力，铸械为兵，守此一谷山川。」

一款以《山海经》与**机关术**为骨的 3D 塔防策略游戏，运行在浏览器里，
**零外部素材** —— 山川、楼阁、水车、齿轮、异兽、纹理、音效，全部在运行时程序化生成。

**五关山海**：自栖梧一谷起，历炎火之山、幽都寒渊、归墟海眼，直至昆仑天阙。
每一关的地脉、水性、草木、屋舍形制、凶兽与机关皆不相同。

在线试玩：**https://disenthrallclaude.github.io/Chinese-style-game/**

视觉基调的拆解见 [docs/style.md](docs/style.md)。

## 玩法

昆仑之墟东南三百里，有谷曰**栖梧**。谷民世代以机关术营生，引溪为力，驱轮为兵。
《山海经》所载凶兽破封而出，自左右两处山口奔涌而下，直取谷心的**社树**。

### 五方山海

| 关 | 地 | 水 | 发力机关 | 招牌凶兽 |
| --- | --- | --- | --- | --- |
| 一 | **栖梧谷** 溪谷梯田、喀斯特峰林 | 溪流 | 水车 | 讙 · 相柳 · 烛龙 |
| 二 | **炎火之山** 赤沙雅丹、风蚀石柱 | **熔岩** | 地火炉 | 狰 · 鬿雀 · 朱厌 |
| 三 | **幽都寒渊** 冰川塔林、冰裂缝 | **冻河** | 水车 | 诸犍 · 寒鸮 · 強良 |
| 四 | **归墟海眼** 群岛栈桥、海蚀礁 | **大海** | 潮汐轮 | 陵鱼 · 奢比尸 · 禺彊 |
| 五 | **昆仑天阙** 悬空玉台、天柱 | **云海** | 云枢 | 土蝼 · 英招 · 开明兽 |

地貌全部写在 `src/world/levels.js` 一份数据里：高程函数、表层配比、兽道走向、
草木族属、屋舍排布、天时色偏。世界与玩法都只认这一份事实。

### 三条核心规则

| 规则 | 说明 |
| --- | --- |
| **引水生力** | 机关不会凭空运转。**水车**（临溪）与**风车**吐纳*机力*，经**传动枢**结成网络送到各处。没接上网的机关直接停机；机力供不应求则全谷射速按比例下降。 |
| **五行相克** | 金克木、木克土、土克水、水克火、火克金。打对属性伤害 **×1.85**，打错只有 **×0.62**。每一波的凶兽属性都在右上角预告里写着。 |
| **昼夜轮转** | 部分波次在夜里来袭：凶兽气血更厚、脚力更快；但谷中灯火通明，机关**射速 +12%**。烛龙更会强行倒转昼夜。 |

### 十二种机关

连弩机（木·速射）· 霹雳车（土·溅射）· 流火筒（火·锥形灼烧）· 寒泉阵（水·减速领域）
金锋轮（金·环身斩击）· 引雷桩（金·连锁闪电）· 风车（发力）· 传动枢（传动）

发力机关随地而变：**水车**（临溪）· **地火炉**（引地脉之火，何处皆可）·
**潮汐轮**（临海，出力最巨）· **云枢**（承云气而转）。每关只开放其中一种。

每种三阶，升阶会实实在在地改变外形 —— 单弩变三连弩、四扇风车变八扇、雷桩长出更多铜环。

### 二十九种凶兽

讙 · 猰貐 · 蠃鱼 · 鵸鵌 · 毕方 · 化蛇 · 相柳 · 九尾狐 · 饕餮 · 帝江 · 穷奇 · 夔 · 烛龙
狰 · 鬿雀 · 火鼠 · 朱厌 · 诸犍 · 狡 · 寒鸮 · 強良 · 陵鱼 · 奢比尸 · 鱄鱼 · 禺彊
土蝼 · 英招 · 陆吾 · 开明兽

每一种都有自己的形制：九首的**开明兽**、操蛇的**強良**、白首赤足的**朱厌**、
人面鱼身的**陵鱼**、四角如羊的**土蝼**⋯⋯ 全部由躯干／肢／翼／尾／首部件拼出，
一族一次 draw call。

各有脾性：**相柳**斩之分身、**饕餮**啃噬机关使其卡死、**九尾狐**为同类加持、
**帝江**免疫减速、**化蛇**发大水淹停水车、**夔**一声雷震瘫周围机关、
**烛龙**边走边回血还会颠倒昼夜。飞行的凶兽（鵸鵌、毕方、穷奇）**不循兽道**，直扑社树。

### 三道秘术

**天雷**（Q）落雷轰击并震慑 · **玄冰**（F）冻结一片 · **归元**（G）十息内全谷机关射速 +70% 且无视断网

## 运行

不需要构建步骤，只要一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或任意等价物（`npx serve`、nginx、GitHub Pages…）。
`three.js` 已随仓库附带在 `vendor/three/`，通过 import map 解析，因此**离线可玩**。

要求：支持 WebGL2 的现代浏览器。引擎自带帧率自适应，掉帧时会自动降低内部渲染分辨率。

## 技术

* **three.js r185**（vendored），ES module + import map，无打包器。
* **全部资源程序化生成**：
  * `src/core/textures.js` —— 木纹、筒瓦、青石、绢帛、铜锈、窗棂、树叶⋯ 用 Canvas2D 逐像素绘制，再由亮度反解法线图与粗糙度图。
  * `src/world/geo.js` / `architecture.js` —— 台基、柱、额枋、斗拱、**反宇飞檐**的中式屋顶曲面（按到檐口的内推距离求坡度，四角起翘）。屋面的**瓦垄**是真几何：网格加密到「每垄两格」，顶点正好落在垄脊与垄沟上。翼角悬风铎，正门列抱鼓石。
  * `src/world/terrain.js` —— 山谷高程场：梯田、环谷山体、喀斯特峰林，向北开一道谷口露出层叠远山。梯田坎口砌石坎，兽道两侧排石牙。
  * `src/game/beasts.js` —— 异兽由躯干／四肢（髋‑膝‑蹄三段）／翼（肩‑肘‑腕拱起、飞羽覆羽分层）／尾／首（吻、眉骨、瞳）等部件拼出，肢体动画写在顶点着色器里，整族凶兽一次 draw call。
* **卡通化**：
  * **墨线**：后期用深度的**二阶差分**描边 —— 斜面上恒为零，只有真正的轮廓与折角才出线，所以山坡不会被误画满。
  * **描边壳**：凶兽另有一层背面外扩壳，与本体共用实例矩阵和同一套顶点动画；法线在生成时按位置焊接过，方盒棱角处不会裂。
  * **卡通光照**（`src/core/toon.js`）：按「直射光占总光量的比例」量化，与曝光、时辰无关，正午和夜里看到的层数一样。
* **渲染**：ACES 调色 + 分离色调、UnrealBloom、基于深度的**丁达尔光柱**、天空烘焙成 PMREM 环境光、轻薄的指数雾（只留空气透视，不糊画面）。
* **音效**：`src/core/audio.js` 用 WebAudio 振荡器与噪声实时合成，无音频文件。
