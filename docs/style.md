# 视觉基调

参照一张「中式机关村寨」概念图：晨光斜照的山谷、青瓦木构的层叠屋舍、
巨大的木水车与齿轮塔、跨溪的石拱桥、悬在檐下的灯笼，以及远处笼在雾里的喀斯特峰林。

游戏把这套调子拆成可程序化生成的部件：

* **构图** —— 前景一道檐廊框住画面两角，中景是青石广场与社树，
  溪水横贯中带，溪北的梯田上叠着村舍与齿轮塔，尽头是敞开的谷口与远山。
* **光** —— 过肩侧逆光（方位角 58°、高度角 46°），影子朝画面左前方拖出，
  屋檐与树冠边缘吃到暖边光；天空烘成 PMREM 提供环境反射。
* **色** —— 阴影偏冷青、高光偏暖金，ACES 之后再压一层分离色调；
  夜里整体转靛蓝，灯笼与窗纸自发光，泛光被推到最亮。
* **气** —— 指数雾负责空气透视，另有一层「掠射雾带」：平视时厚、俯视时几乎不可见，
  于是雾只会横挂在山腰，而不会糊住脚下的广场。
